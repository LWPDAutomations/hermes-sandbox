# Regels voor agent

- Werk altijd op een nieuwe branch, nooit direct op `main`.
- Lever werk op via pull request; Lars merget zelf of vraagt expliciet.
- Commit nooit API keys, tokens, wachtwoorden, `.env`-bestanden, of klantdata/persoonsgegevens onder AVG.
- Verwijder of overschrijf geen git-geschiedenis (geen force push).
