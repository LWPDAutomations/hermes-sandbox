# Rules for agents

- Always work on a new branch, never directly on `main`.
- Deliver work as a pull request. Lars merges, unless he says otherwise.
- Never commit API keys, tokens, passwords, `.env` files, or customer/personal data (GDPR).
- Never rewrite or delete git history. No force push.
- If you are blocked — missing credentials, unclear requirements, a decision that isn't yours — stop and report what you need. Do not guess and do not work around it.
- State what you actually verified. If you did not run it, say so.
